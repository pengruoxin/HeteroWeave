# Third-party code and attribution

This repository contains adaptations of DeRy and MMClassification code and a
vendored legacy timm tree under `third_package/timm`. It also calls torchvision,
timm, pymoo, Hugging Face Transformers/Datasets, and fvcore.

Before public release, retain the copyright headers already present in source
files and add the complete license and notice texts required by the upstream
versions. Do not apply a new repository-wide license until compatibility with
those upstream terms and the authors' intended release policy has been
confirmed.
